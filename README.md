# Decathlon Sales SQL Project

## Overview

This project contains SQL queries used to analyze Decathlon sales data. The queries demonstrate SQL concepts such as filtering, grouping, sorting, aggregate functions, Common Table Expressions (CTEs), and window functions.

## Skills Used

* SQL
* SELECT
* WHERE
* GROUP BY
* ORDER BY
* Aggregate Functions
* Common Table Expressions (CTEs)
* Window Functions

## Project Goal

The goal of this project is to practice SQL by solving real-world sales analysis problems and improving data analysis skills.
